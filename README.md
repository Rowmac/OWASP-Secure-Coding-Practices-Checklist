# OWASP-Secure-Coding-Practices-Checklist

An Excel-based checklist for reviewing secure coding practices across application development.

**Coverage includes:**
- Input validation and output encoding
- Authentication and session management
- Access control and cryptographic practices
- Error handling, logging, and data protection
- Communication security and system configuration
- Database security, file management, and memory management
- General secure coding practices

### How to use
1. Download the Excel checklist from the `checklists/` directory.
2. Review each applicable control during code review or security testing.
3. Record the status, evidence, and remediation actions.
4. Track failed controls through remediation and retesting.

**Note:** This checklist supports secure coding reviews. It does not, by itself, establish OWASP compliance or replace application security testing.
